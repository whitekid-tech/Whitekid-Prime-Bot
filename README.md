## 📲 CONNECT YOUR WHATSAPP

Whitekid Prime provides WhatsApp connection commands through its Telegram bot.

### Step 1 — Open Telegram

Click the button below to open the official bot.

<div align="center">

<a href="https://t.me/whitekid_prime_bot">
  <img src="https://img.shields.io/badge/✈️_OPEN_WHITEKID_PRIME-0088CC?style=for-the-badge&logo=telegram&logoColor=white" alt="Open Whitekid Prime">
</a>

</div>

### Step 2 — Start the bot

Open the Telegram conversation and send:

`/start`

### Step 3 — Choose a connection method

**Option A: Pairing code**

Send the pairing command using your full international phone number.

Example:

`/pair 2637XXXXXXXX`

Replace the example with your own WhatsApp number, including the country code.

**Option B: QR code**

Send:

`/link`

Follow the instructions provided by the bot to connect your WhatsApp account.

### Step 4 — Finish connecting

For a pairing code, open WhatsApp and navigate to:

**Settings → Linked devices → Link a device → Link with phone number**

Enter the pairing code returned by the bot.

For QR linking, use WhatsApp's linked-device scanner to scan the QR code.

### Step 5 — Start using Prime

Once the connection succeeds, open your linked WhatsApp account and send:

`.menu`

Explore the commands available in your running version of Whitekid Prime.

> 🔐 **Security:** Never share your WhatsApp pairing code, QR code, or session credentials with strangers. A linked session can grant access to your WhatsApp account.

## ⚙️ INSTALLATION

### Requirements

- Node.js
- npm
- Git
- A compatible hosting environment
- Required API credentials for the services you want to use

### 1. Clone the repository

```bash
git clone https://github.com/whitekid-tech/Whitekid-Prime-Bot-.git
```

### 2. Enter the project directory

```bash
cd Whitekid-Prime-Bot-
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure the environment

Review the project configuration and identify the credentials required by your deployment.

Use environment variables for private credentials instead of committing API keys or tokens to GitHub.

### 5. Start the application

```bash
node index.js
```

The application is configured to use port `3000` by default, or the port provided through the `PORT` environment variable.

When the server starts successfully, its health endpoint is available at:

`http://localhost:3000/health`

For a hosted deployment, replace `localhost:3000` with your hosting provider's assigned address and port.

You can deploy Whitekid Prime to a compatible Node.js hosting provider.

## 🛠️ TECHNOLOGIES

Whitekid Prime uses a Node.js-based application architecture with integrations that include:

- **Node.js** — JavaScript runtime
- **Express** — HTTP server
- **Baileys** — WhatsApp Web connection
- **Telegram Bot API** — Telegram interaction
- **OpenAI SDK** — AI integration
- **Axios** — HTTP requests
- **QRCode** — QR-code generation
- **Sharp** — Image processing
- **FFmpeg integration** — Audio and media processing
- **GitHub API integration** — Repository and session-related operations

Additional libraries and external APIs are used for supported media, search, and utility functions.
